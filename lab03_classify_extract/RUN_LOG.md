## 読み取れること（2026-10-18 の本物の実行から）

- **飽和**: v1 120 件は Opus 5.5・Sonnet 5.5 とも 120/120。誤り率の上限は約 3%（Wilson）。この試験ではモデルの差は見えない
- 費用は Opus 0.826 USD / Sonnet 0.366 USD（同じ 120 件、2.3 倍）。**正答が同じなら安い方を選ぶ根拠になる**（lab09 の非劣性で確かめる）
- 境目を突く v2 難問 48 件を作ったが、Sonnet は 48/48。Opus は回していない（Sonnet が満点のため。費用を抑えた）
- 抽出 48 件も Sonnet で全項目 100%（strict でも）。Opus は回していない
- 🔴 台本の線: 「この程度の手引きつき分類・抽出は、今のモデルでは試験が飽和する。評価の仕事は、差が出る問いを作ること・変更で壊れないことを見張ることに移る」
- 自信（confidence）は全問正解なのに 0.78〜0.93 と低めに言う → ECE 0.07〜0.10 は「自信が低すぎる」側のずれ
